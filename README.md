# 我的第一个项目

这是一个用于学习 GitHub 的简单待办清单项目。

## 功能

- 添加待办事项
- 勾选完成
- 删除单项
- 清除所有已完成事项
- 使用浏览器本地存储保存数据

## 文件说明

- `index.html`：网页结构
- `style.css`：网页样式
- `script.js`：网页交互逻辑
- `README.md`：项目说明

## 如何使用

1. 下载或克隆本项目。
2. 用浏览器打开 `index.html`。
3. 输入内容并点击“添加”。

## 上传到 GitHub

1. 在 GitHub 创建一个空仓库。
2. 进入仓库后，点击“上传一个现有的文件”。
3. 把本项目中的文件拖入上传页面。
4. 填写提交说明并提交。

## 学习目标

- 了解 GitHub 仓库的基本结构
- 学会上传文件
- 学会使用 README 说明项目
